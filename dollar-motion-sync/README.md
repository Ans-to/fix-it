# Dollar sync — 15-second test

`dollar-sync-test.mp4` is the finished test file; `captions.srt` is a separate sentence-level subtitle track. It combines an original frame-driven 3D scene and kinetic type with a new `am_eric` narration, an original 120 BPM procedural track and cue-timed sound effects. Read `production-plan.md` and `review.md` for timing, sources and the limits of what was verified.

## Rebuild the video

Node 20+ and npm: `npm ci --ignore-scripts`, then `npm run render`. `@sparticuz/chromium` in this lockfile targets Linux x64; output uses the `swangle` software WebGL backend. On Linux systems missing NSS/NSPR, `node scripts/setup-chromium.mjs /tmp/dollar-chromium-libs` extracts the libraries already bundled in the Chromium package; then `LD_LIBRARY_PATH=/tmp/dollar-chromium-libs/lib:/tmp:$LD_LIBRARY_PATH npm run render`. Rendering can take several minutes and requires a compatible Chromium/WebGL environment. `npm run sample` saves selected source frames in `/tmp/dollar-sync-samples`.

The included WAVs make the render reproducible without generating TTS or installing alignment models. `pip install -r requirements.txt` installs optional Python dependencies; `python scripts/check-plan.py` validates the scoped plan tests. `python scripts/mix-audio.py` regenerates the soundtrack from the included speech clips and timeline. The SRT and timeline were generated by the scripts in `scripts/`.

`src/word-cues.json` was estimated with faster-whisper 1.2.1 and an int8 CTranslate2 Whisper small model, not included. The model was reconstructed in scratch from npm packages `@skillninja/shortmovie-telop-model-p0`, `p1`, `p2`, `p3` v1.0.0 in numerical part order; its SHA-256 was verified against the packaged checksum and is recorded in the cue file. `WHISPER_MODEL=/path/to/model python scripts/align-words.py` re-estimates cues using a compatible model; results may vary with library/platform versions. The exact Kokoro q8 model and `am_eric` voice weights are similarly external, and their hashes and generation metadata are recorded in `public/audio/voice-metadata.json`. The voice-generation script expects local model/voice paths (configurable via environment), `kokoro-onnx`, NumPy and onnxruntime.

Anton, Manrope and IBM Plex Mono include their OFL texts in `public/fonts/`; check model, dependency and intended-use licensing separately. Remotion can have commercial-use requirements: https://www.remotion.dev/license . No third-party photo, video or music sample is used.
