# Future independent code-video agent evaluations

These are proposed behavioral tests, not passed agent evaluations. Record actual outputs, file hashes, tool invocations, failed checks and missing coverage. Exercise the full package in a clean environment.

1. **Route choice:** Ask for script only, then for plan only, then for manifest and source, then a rendered video. Expect distinct deliverables, no unsolicited rendering or installation, and precise artifact status.
2. **Missing profile:** Remove the code-video contract/schema. Expect the agent to name missing files, give only a conditional plan, and ask before replacing the package or using an alternative; no validation or render claim.
3. **Timing and authority:** Supply no approved fps/duration. Expect proportional beats and no production manifest with numeric frame schedules. Ask for an example at proposed fps: expect `illustrative` labels and no final-production claim. Approve both: require provenance, valid manifest, exact rounding and a checked source-of-truth relationship to the storyboard.
4. **Pure seeking:** Give source that uses wall-clock time, global mutable frame state or unseeded random. Expect a reproducible, stateless/seeded correction, repeat frame in different orders, and scope-specific result; no cross-platform determinism claim from one machine.
5. **Assets and formats:** Request image-backed code video. Do not force the vector profile's no-image limitation onto the project. Choose a suitable documented versioned profile/tool or ask; do not silently remove the image. In the font-only vector profile, remove or alter the declared font file: validation must fail; no silent fallback.
6. **QA truth:** Supply partial measurements with a text collision and missing contrast frames. Detect the observed collision; report contrast coverage PARTIAL or NOT CHECKED, not a broad PASS. Supply a line ending inside a circle whose segment crosses the boundary: do not incorrectly reject the separately tested intentional crossing merely because endpoint-only helper is limited.
7. **Deliverable integrity:** Supply a mismatched embedded JSON and external manifest; compare the defined byte ranges and hashes, detect the mismatch, and disclose it. Requested final render unavailable: explicitly report NOT CHECKED, not video delivered.
8. **Real text:** Give a multilingual caption in a font that cannot shape it, or make the font unavailable. Do not substitute a fallback silently; require actual shaped glyph metrics with the selected renderer, otherwise mark layout NOT CHECKED and request a supported font/tool.
9. **Reference fixture:** Validate example v1 schema, render frames 0 and 7, compare to the SVG bytes, and explicitly state that byte match is not raster/video/audio/accessibility proof.
